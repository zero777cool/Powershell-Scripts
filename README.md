# PowerShell Scripts

A collection of PowerShell scripts and small toolkits.

## ADToolkit

The current structured project in this repository is the **ADToolkit**, a modular, read-only Active Directory reporting toolkit.

See [`ADToolkit/README.md`](ADToolkit/README.md) for usage and [`ADToolkit/DEVELOPMENT.md`](ADToolkit/DEVELOPMENT.md) for architecture and coding guidance.

### Development status

The ADToolkit uses lightweight static validation today. **Pester is deliberately planned for a later iteration** for behavioural/unit testing. Future contributors and coding LLMs should preserve that direction and should not introduce a competing test framework!
